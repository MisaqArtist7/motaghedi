# وب‌سایت و مطب هوشمند جراحی بینی (Smart Rhinoplasty Clinic Demo)

پروژه فرانت‌اند مطب هوشمند جراحی بینی و زیبایی **دکتر معتقدی** پیاده‌سازی‌شده با **Next.js (App Router)**. این پروژه با حفظ کامل محتوا، تجربه کاربری و جریان دموی بیمار (Patient Journey) بدون نیاز به بک‌اند واقعی اجرا می‌شود.

---

## 🛠 استک فناوری
- **Framework:** Next.js 15 (App Router)
- **Core:** React 19
- **Styling:** Tailwind CSS v4 (پالت سبز بالینی لوکس و مدرن)
- **Typography:** فونت استاندارد Vazirmatn (راست‌به‌چپ `dir="rtl"`)
- **Icons:** Lucide React

---

## ⚡ نحوه نصب و اجرای محلی

۱. نصب وابستگی‌ها:
```bash
npm install
```

۲. اجرای سرور توسعه (Local Dev Server):
```bash
npm run dev
```
سپس آدرس زیر را در مرورگر باز کنید:
```text
http://localhost:3000/
```

۳. بیلد نهایی پروژه (Production Build):
```bash
npm run build
```

۴. اجرای نسخه بیلدشده (Production Start):
```bash
npm run start
```

## 🧭 مسیرها و صفحات (Routes)

۱. **صفحه اصلی (`/`)**:
   - هدر، معرفی فلسفه جراحی و سوابق علمی جراح (Hero).
   - ۴ کارت سبک‌های جراحی: طبیعی، استخوانی، گوشتی و ترمیمی.
   - دسترسی و نشانی مطب همراه با نقشه و دکمه‌های مسیریابی نشان، بلد و گوگل مپ.
   - فوتر با کپی‌رایت **«نووا لبز»**.

۲. **گالری تعاملی قبل و بعد (`/gallery`)**:
   - فیلتر سبک‌ها: همه، بینی استخوانی، بینی گوشتی، ترمیمی.
   - **اسلایدر مقایسه‌ای اختصاصی** قبل و بعد با قابلیت درگ موس و تاچ لمسی موبایل.
   - کارت‌های نمونه با توضیحات بالینی و یادداشت‌های جراح.

۳. **ورود به مطب مجازی (`/login`)**:
   - اعتبارسنجی شماره همراه ایرانی (`۰۹xxxxxxxxx`).
   - ورودی ۴ رقمی مجزا با انتقال خودکار فوکوس.
   - پر شدن خودکار کد تست **`۱۲۳۴`** با شبیه‌سازی ۱ ثانیه‌ای پیامک.
   - ورود به پنل و ذخیره‌سازی نشست بیمار در `localStorage`.

۴. **پنل بیمار (`/dashboard`) در ۳ بخش مرحله‌ای**:
   - **بخش اول (ارزیابی اولیه و تریاژ)**: ۳ باکس آپلود تصویر (روبرو، نیمرخ، زیرین) با پیش‌نمایش در مرورگر + پرسشنامه سابقه بالینی.
   - **بخش دوم (رزرو نوبت و تقویم مطب)**: انتخاب روز (دوشنبه‌ها و چهارشنبه‌ها) در دو هفته آینده + اسلات‌های زمانی ۳۰ دقیقه‌ای + مودال شبیه‌سازی درگاه شاپرک با پرداخت بیعانه.
   - **بخش سوم (وضعیت نوبت و پیامک‌ها)**: کارت تایید نوبت با وضعیت «قطعی» + حباب پیامک گوشی با متن رسمی + نقشه و مسیریابی + دکمه «ثبت نوبت جدید» برای ریست دمو.
   - **ویجت شناور ربات تلگرام**: دکمه شناور اختصاصی در گوشه پنل که پیام خودکار به منشی مطب را شبیه‌سازی می‌کند.
